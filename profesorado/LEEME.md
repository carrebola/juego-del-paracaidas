# Material del profesorado

No entregar esta carpeta a los equipos. Ellos descargan `inicio/` (interfaz + JS vacío) y abren `EMPIEZA_AQUI.md`. La solución modular de aquí es solo referencia docente.

## Contenido

| Recurso | Uso |
|---|---|
| [`solucion/`](solucion/) | Juego completo (misma estructura que `inicio/`) |
| [`herramientas/comprobar.cjs`](herramientas/comprobar.cjs) | Pruebas |
| [`PLAN.md`](PLAN.md) | Sesiones |
| [`GUIA.md`](GUIA.md) | Corrección |

```sh
node profesorado/herramientas/comprobar.cjs
```

## Con los equipos

1. Enlazad la plantilla; que lean **Empieza aquí**.
2. Cada equipo crea su repo con el contenido de `inicio/`.
3. Seguid los PR; al final usad `inicio/CONCURSO.md` + esta guía.

Solución de referencia: `solucion/index.html`.
